##  전체 구조

> 데이터 수집부터 종목 추천까지 4단계 멀티스테이지 스크리닝 파이프라인

데이터 수집 (yfinance, pykrx)
↓
피처 엔지니어링 (기술적 지표 + 수학적 피처)
↓
시장 국면 판단 (bull / bear / neutral)
↓
멀티스테이지 스크리닝
├─ 섹터 로테이션 (강한 섹터 top3)
├─ 랜덤포레스트 스크리닝
├─ LSTM 최종 선택
└─ 뉴스 감성분석 보정
↓
주간 top3 종목 추천

##  핵심 모듈

### 1. 시장 국면 판단
> S&P 500 / 코스피 기반으로 현재 시장이 bull/bear/neutral인지 판단
> bear 국면에서는 투자를 중단하고 현금 유지

```python
score = 0
if sp500 > ma50:  score += 1  # 중기 추세
if sp500 > ma20:  score += 1  # 단기 추세
if vix < 20:      score += 1  # 공포 지수
if ret_1w > 0:    score += 1  # 단기 모멘텀
if ret_1m > 0:    score += 1  # 중기 모멘텀

if score >= 3: return "bull"
elif score <= 1: return "bear"
else: return "neutral"
```
### 2. 섹터 로테이션
> 매주 섹터별 모멘텀을 계산해 강한 섹터 top3를 선택
> 강한 섹터 내 종목만 스크리닝 대상으로 한정

### 3. 랜덤포레스트 스크리닝
> 기술적 지표 기반 피처로 5일 후 상승 확률 예측
> 확률 상위 종목을 다음 단계로 전달

### 4. LSTM 최종 선택
> 시계열 패턴을 학습해 최종 top3 종목 선택
> 랜덤포레스트로 걸러진 종목에만 적용

### 5. 뉴스 감성분석
> VADER + 네이버 뉴스 API로 종목별 감성 점수 계산
> 감성 점수가 낮은 종목 제외

##  피처 엔지니어링

> 주가/거래량 데이터에서 ML 모델 입력 피처를 생성
> 기존 기술적 지표 외 수학적 방법론으로 독립적인 피처 탐색

**기술적 지표 피처**
| 피처 | 설명 |
|------|------|
| mom1w, mom1m, mom3m | 단기·중기·장기 모멘텀 |
| RSI | 과매수/과매도 판단 |
| MACD | 단기 추세 강도 |
| vol_change, vol_vs_avg | 거래량 변화 및 강도 |
| golden_cross | 이평선 교차 신호 |

**수학적 피처 탐색**
| 피처 | 설명 |
|------|------|
| ma20_curvature | 이평선 2차 미분 (변곡점) |
| curvature_2d | 두 이평선 2D 궤적 곡률 |
| Path Signature | 가격·거래량 경로 패턴 추출 |
| K-Means 클러스터 | 기술적 지표 패턴 분류 |

> 이평선 정렬 구간에서 변곡점 8개 이상인 종목의 상승 적중률: **58.55%**

**KOSPI 추가 피처**
| 피처 | 설명 |
|------|------|
| trading_value | 거래대금 (21일 평균 대비) |
| OBV | 누적 거래량 방향 |
| 외국인/기관 순매수 | 수급 신호 (개발 중) |
